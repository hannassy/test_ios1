# Своє — личное iOS-приложение

Одно приложение вместо нескольких. Меню из независимых разделов: график отключений ДТЭК, аудиокниги, Debug. Без App Store, только для своего телефона.

## Что внутри

| Раздел | Что делает |
|--------|-----------|
| **Світло** | График отключений ДТЭК: несколько адресов, факт на сегодня и прогноз на неделю, виджет на домашнем экране |
| **Аудиокниги** | Импорт ZIP (mp3/m4a/m4b), плеер с фоном, скоростью и памятью позиции |
| **Debug** | Отчёты об ошибках с контекстом; кнопка «Скопировать» для отправки в чат |

## Запуск

### 1. Установи Xcode

Если Xcode не установлен — [скачай из App Store](https://apps.apple.com/app/xcode/id497799835). Это бесплатно.

### 2. Сгенерируй проект

```bash
cd /Users/ppota/Projects/ios.phoneApp
./setup.sh   # установит XcodeGen и создаст phoneApp.xcodeproj
```

Если `brew` не установлен:
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
./setup.sh
```

### 3. Открой в Xcode и настрой подпись

```bash
open phoneApp.xcodeproj
```

В Xcode:
1. Выбери target **phoneApp** → Signing & Capabilities → Team: свой Apple ID
2. То же для **OutageWidget**
3. Подключи iPhone кабелем или по Wi-Fi
4. Запусти ⌘R

> Бесплатная подпись живёт 7 дней. Через неделю просто запусти ⌘R снова из Xcode.

## Добавить новый раздел

1. Создай папку `phoneApp/Features/MyFeature/`
2. Реализуй `AppFeature` в файле `MyFeatureFeature.swift`
3. Добавь одну строку в `FeatureRegistry.swift`:
   ```swift
   MyFeature(diagnosticLog: log),
   ```

Всё остальное не трогается.

## Адрес для графика ДТЭК

При первом открытии раздела «Світло» откроется мастер: выбери регион (Одесса, Днепр, Киев...), введи город, улицу и дом. Можно добавить несколько мест — например, «Дом» и «Родители» — и переключаться между ними. Виджет показывает статус выбранного места.

## Структура файлов

```
ios.phoneApp/
├── project.yml              # XcodeGen: таргеты, зависимости, группы
├── setup.sh                 # Скрипт генерации проекта
├── phoneApp/
│   ├── App/                 # Оболочка: меню, реестр, диагностика
│   ├── Features/
│   │   ├── Outages/         # Световой модуль
│   │   ├── Audiobooks/      # Аудиокниги
│   │   └── Debug/           # Журнал ошибок
│   └── Resources/           # String Catalog и ресурсы
├── OutageWidget/            # Расширение виджета
└── phoneAppTests/              # Тесты без сети
```
